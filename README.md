# 📊 نبض بازار 

### داشبورد هوشمند تحلیل تکنیکال بازار رمزارزها

**نبض بازار** یک نرم‌افزار دسکتاپ برای دریافت، پردازش و تحلیل داده‌های بازار رمزارزهاست که با زبان پایتون توسعه داده شده است. این برنامه با اتصال مستقیم به API عمومی صرافی‌های ارز دیجیتال، اطلاعات کندل‌های معاملاتی را دریافت می‌کند، اندیکاتورهای پرکاربرد تحلیل تکنیکال را به‌صورت خودکار محاسبه می‌کند و نتایج را در قالب یک رابط کاربری گرافیکی، زیبا و کاربردی نمایش می‌دهد.

رابط کاربری برنامه با استفاده از فناوری‌های وب طراحی شده و در محیط دسکتاپ به کمک **pywebview** اجرا می‌شود. برای استفاده از قابلیت‌های اصلی برنامه، نیازی به دریافت API Key، ساخت حساب کاربری در صرافی یا ارائه اطلاعات ورود نیست.

هدف نبض بازار، فراهم‌کردن محیطی ساده، سریع و کاربردی برای مشاهده داده‌های بازار، بررسی وضعیت اندیکاتورها و آماده‌سازی اطلاعات موردنیاز برای تحلیل تکنیکال است.

## ✨ امکانات و قابلیت‌ها

- **دریافت مستقیم اطلاعات بازار:** دریافت کندل‌های معاملاتی از صرافی‌های پشتیبانی‌شده با استفاده از کتابخانه CCXT.
- **محاسبه خودکار اندیکاتورها:** محاسبه شاخص‌های پرکاربرد تحلیل تکنیکال و نمایش آخرین مقادیر آن‌ها.
- **نمایش اطلاعات قیمت:** مشاهده قیمت بازشدن، بالاترین قیمت، پایین‌ترین قیمت، قیمت بسته‌شدن و حجم معاملات.
- **نمایش تغییرات قیمت:** محاسبه درصد تغییر قیمت نسبت به کندل قبلی و نمایش دامنه نوسان آخرین کندل.
- **جدول کامل کندل‌ها:** نمایش اطلاعات تاریخی کندل‌ها با قرارگرفتن جدیدترین کندل در ابتدای جدول.
- **تاریخ شمسی:** نمایش تاریخ و زمان کندل‌ها با فرمت قابل‌استفاده برای کاربران فارسی‌زبان.
- **خروجی اکسل:** ذخیره داده‌های دریافت‌شده و اطلاعات اندیکاتورها در فایل Excel با فرمت `.xlsx`.
- **کپی جدول:** کپی ستون‌های قابل‌مشاهده برای انتقال سریع اطلاعات به اکسل یا سایر نرم‌افزارها.
- **نمایش جزئیات اندیکاتورها:** امکان فعال‌سازی نمایش تمام مقادیر اندیکاتورها در جدول کندل‌ها.
- **تم روشن و تیره:** انتخاب ظاهر متناسب با سلیقه کاربر و شرایط استفاده.
- **رابط کاربری واکنش‌گرا:** سازگاری با اندازه‌های مختلف پنجره دسکتاپ.
- **پشتیبانی از چند صرافی و تایم‌فریم:** انتخاب صرافی، نماد معاملاتی، بازه زمانی و تعداد کندل‌های موردنیاز.
- **بدون نیاز به API Key:** استفاده از اطلاعات عمومی بازار، بدون نیاز به ثبت کلید خصوصی API صرافی.

## 📈 اندیکاتورهای تحلیل تکنیکال

نبض بازار مجموعه‌ای از اندیکاتورهای کاربردی را محاسبه می‌کند تا بررسی وضعیت قیمت، روند، مومنتوم و حجم معاملات آسان‌تر شود.

| اندیکاتور | تنظیمات | کاربرد |
|---|---|---|
| RSI | دوره ۱۴، روش Wilder | بررسی مومنتوم و شرایط احتمالی اشباع خرید یا فروش |
| Bollinger Bands | دوره ۲۰، انحراف معیار ۲ | بررسی نوسان قیمت و موقعیت آن نسبت به باندها |
| MACD | تنظیمات ۱۲، ۲۶، ۹ | بررسی مومنتوم و تغییرات احتمالی روند |
| Ichimoku | تنکان‌سن ۹ و کیجون‌سن ۲۶ | بررسی موقعیت قیمت و رابطه خطوط پایه و تبدیل |
| Volume Analysis | میانگین ۲۰ کندل | مقایسه حجم جاری با میانگین حجم معاملات |

### تحلیل وضعیت حجم معاملات

برنامه حجم هر کندل را با میانگین حجم ۲۰ کندل مقایسه می‌کند و وضعیت آن را در یکی از گروه‌های زیر قرار می‌دهد:

- کم
- عادی
- بالا
- بسیار بالا

این دسته‌بندی به شناسایی تغییرات نسبی حجم معاملات کمک می‌کند؛ با این حال، افزایش یا کاهش حجم به‌تنهایی جهت حرکت آینده قیمت را مشخص نمی‌کند.

در نسخه فعلی، امکان دریافت داده‌های بازار از صرافی‌های زیر در نظر گرفته شده است:

- Bitget

دریافت اطلاعات از طریق رابط‌های عمومی بازار انجام می‌شود. در دسترس بودن داده‌ها، نمادها و بازه‌های زمانی ممکن است با توجه به API و محدودیت‌های هر صرافی متفاوت باشد.

## ⏱️ تایم‌فریم‌های معاملاتی

برنامه از تایم‌فریم‌های زیر پشتیبانی می‌کند:

| تایم‌فریم | مقدار |
|---|---|
| یک دقیقه | `1m` |
| پنج دقیقه | `5m` |
| پانزده دقیقه | `15m` |
| سی دقیقه | `30m` |
| یک ساعت | `1h` |
| چهار ساعت | `4h` |
| روزانه | `1d` |
| هفتگی | `1w` |

تعداد کندل‌های قابل‌دریافت نیز از **۱۰ تا ۵۰۰ کندل** قابل تنظیم است.

اگر صرافی انتخاب‌شده از تایم‌فریم موردنظر پشتیبانی نکند یا دریافت اطلاعات با خطا مواجه شود، برنامه می‌تواند خطای دریافت داده را نمایش دهد. امکان ارائه فهرست تایم‌فریم‌های مجاز به پیاده‌سازی مدیریت خطا در نسخه مورد استفاده بستگی دارد.

## 🖥️ راهنمای نصب و راه‌اندازی

### ۱. پیش‌نیازها

برای اجرای برنامه به موارد زیر نیاز دارید:

- Python نسخه ۳.۹ یا بالاتر
- اتصال به اینترنت برای دریافت اطلاعات بازار
- نصب وابستگی‌های موردنیاز پروژه

### ۲. دریافت فایل‌های پروژه

فایل‌های پروژه را در یک پوشه قرار دهید. حداقل فایل‌های موردنیاز عبارت‌اند از:

```text
├── main_app.py
├── requirements.txt
└── README.md
```

### ۳. ایجاد محیط مجازی

استفاده از محیط مجازی پایتون توصیه می‌شود تا وابستگی‌های پروژه از سایر برنامه‌های نصب‌شده جدا بمانند.

در ترمینال ویندوز، وارد پوشه پروژه شوید و دستورات زیر را اجرا کنید:

```bat
python -m venv venv
venv\Scripts\activate
```

در لینوکس و macOS:

```bash
python3 -m venv venv
source venv/bin/activate
```

### ۴. نصب وابستگی‌ها

روش پیشنهادی:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

اگر فایل `requirements.txt` در دسترس نیست، وابستگی‌های اصلی را می‌توان به‌صورت دستی نصب کرد:

```bash
pip install pywebview ccxt pandas openpyxl
```

توجه داشته باشید که اگر برنامه برای تبدیل تاریخ میلادی به شمسی از کتابخانه جداگانه‌ای استفاده کند، آن کتابخانه نیز باید در فهرست وابستگی‌ها نصب شود.

### ۵. اجرای برنامه

پس از نصب موفق وابستگی‌ها، دستور زیر را اجرا کنید:

```bash
python main_app.py
```

در صورت نصب صحیح پیش‌نیازها، پنجره دسکتاپ برنامه باز خواهد شد.

## 🧭 راهنمای استفاده از برنامه

۱. **انتخاب صرافی:** صرافی موردنظر خود را از فهرست انتخاب کنید.

۲. **واردکردن نماد معاملاتی:** نماد موردنظر را وارد کنید؛ برای مثال:

```text
BTC/USDT
ETH/USDT
SOL/USDT
```

در صورت پشتیبانی برنامه از تکمیل خودکار نماد، واردکردن `BTC` به‌تنهایی نیز به `BTC/USDT` تبدیل خواهد شد.

۳. **انتخاب تایم‌فریم:** بازه زمانی کندل‌ها را متناسب با نوع بررسی خود انتخاب کنید.

۴. **تعیین تعداد کندل‌ها:** تعداد کندل‌های موردنیاز را بین ۱۰ تا ۵۰۰ مشخص کنید.

۵. **دریافت داده‌ها:** روی دکمه «دریافت داده» کلیک کنید. در صورت پشتیبانی رابط کاربری، فشردن کلید Enter در فیلد نماد نیز همین عملیات را انجام می‌دهد.

۶. **بررسی اطلاعات:** پس از دریافت موفق داده‌ها، اطلاعات قیمت، درصد تغییر، دامنه نوسان، اندیکاتورها و جدول کندل‌ها نمایش داده می‌شوند.

۷. **نمایش تمام اندیکاتورها:** برای مشاهده مقادیر اندیکاتورها در هر کندل، گزینه «نمایش همه اندیکاتورها» را فعال کنید.

۸. **ذخیره اطلاعات:** با استفاده از دکمه «ذخیره در اکسل»، اطلاعات دریافت‌شده را در قالب فایل `.xlsx` ذخیره کنید.

۹. **کپی جدول:** با انتخاب «کپی جدول»، اطلاعات ستون‌های قابل‌مشاهده را برای استفاده در نرم‌افزارهای دیگر کپی کنید.

ویژگی‌های خروجی عبارت‌اند از:

## ⚠️ نکات مهم درباره دقت داده‌ها

**توجه به وضعیت آخرین کندل برای تحلیل تکنیکال ضروری است.**

در بسیاری از صرافی‌ها، آخرین کندل دریافتی ممکن است هنوز در حال تشکیل باشد. بنابراین، مقادیر قیمت بازشدن، بالاترین قیمت، پایین‌ترین قیمت، قیمت بسته‌شدن و حجم آن می‌توانند تا پایان بازه زمانی تغییر کنند.

در این شرایط، مقدار فیلد `close` برای آخرین کندل لزوماً به معنای قیمت بسته‌شدن نهایی و قطعی نیست؛ بلکه ممکن است آخرین قیمت ثبت‌شده تا زمان دریافت اطلاعات را نشان دهد.

برای مثال، اگر تایم‌فریم یک‌ساعته انتخاب شده باشد و کندل فعلی هنوز به پایان نرسیده باشد، قیمت بسته‌شدن گزارش‌شده ممکن است با مقدار نهایی آن کندل متفاوت باشد.

پیش از استفاده از اطلاعات برای تحلیل، موارد زیر را در نظر بگیرید:

- وضعیت آخرین کندل را با اطلاعات همان نماد و تایم‌فریم در صرافی مربوطه مقایسه کنید.
- در صورت نیاز به مقادیر نهایی، از آخرین کندل کاملاً بسته‌شده استفاده کنید.
- به زمان دریافت اطلاعات و تأخیر احتمالی API توجه داشته باشید.
- مقادیر اندیکاتورها را متناسب با داده‌های ورودی و وضعیت بسته یا باز بودن کندل تفسیر کنید.
- برای تصمیم‌گیری معاملاتی، تنها به یک اندیکاتور یا یک سیگنال اتکا نکنید.
- حتما قیمت کندل ها و اندیکاتورها را با صرافی به صورت کامل بررسی کنید ممکن است قیمت کندل ها و اندیکاتورها مقادیر را درست نمایش ندهند. 

**سلب مسئولیت:** نبض بازار ابزاری برای دریافت و بررسی داده‌های بازار و محاسبه اندیکاتورهای تکنیکال است. خروجی‌های برنامه تضمینی برای سودآوری ندارند و نباید به‌تنهایی مبنای تصمیم‌گیری مالی قرار گیرند. بازار رمزارزها با ریسک بالایی همراه است و مسئولیت تصمیم‌های معاملاتی بر عهده کاربر است.

## 🔧 افزودن صرافی جدید

برای اضافه‌کردن یک صرافی جدید، در صورتی که توسط نسخه نصب‌شده CCXT پشتیبانی شود، مراحل کلی زیر را دنبال کنید:

۱. شناسه رسمی صرافی را در فهرست `SUPPORTED_EXCHANGES` اضافه کنید.

۲. گزینه متناظر را به فهرست کشویی صرافی‌ها در HTML، با شناسه‌ای مانند `exchange`، اضافه کنید.

۳. بررسی کنید که روش ایجاد نمونه صرافی، دریافت OHLCV، نمادهای معاملاتی و تایم‌فریم‌های موردنیاز به‌درستی پشتیبانی شوند.

۴. خطاهای احتمالی مانند محدودیت درخواست، نماد نامعتبر، تایم‌فریم پشتیبانی‌نشده و قطعی ارتباط را مدیریت کنید.

۵. عملکرد صرافی جدید را با چند نماد و تایم‌فریم مختلف آزمایش کنید.

مستندات رسمی CCXT مرجع مناسبی برای بررسی شناسه صرافی‌ها و قابلیت‌های آن‌هاست:

https://docs.ccxt.com/
