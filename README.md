

# نبض بازار

داشبورد دسکتاپ برای دریافت کندل‌های بازار رمزارزها از صرافی‌ها و محاسبه خودکار اندیکاتورهای تحلیل تکنیکال. برنامه با پایتون نوشته شده و رابط کاربری آن در یک پنجره دسکتاپ (pywebview) اجرا می‌شود. نیازی به API Key یا ساخت حساب کاربری در صرافی نیست.

## این برنامه چه کاری انجام می‌دهد؟

- کندل‌های یک نماد (مثلاً `BTC/USDT`) را مستقیم از صرافی دریافت می‌کند.
- اندیکاتورها را روی داده‌ها محاسبه می‌کند و مقدار آخرین کندل را در کارت‌های بالای صفحه نشان می‌دهد.
- همه کندل‌ها را در یک جدول نمایش می‌دهد؛ جدیدترین کندل بالای جدول است.
- تاریخ کندل‌ها را به **شمسی** نشان می‌دهد.
- خروجی را به صورت فایل **اکسل** ذخیره می‌کند یا جدول را کپی می‌کند.
- تم تیره و روشن دارد و روی پنجره‌های کوچک هم درست نمایش داده می‌شود.

### اندیکاتورهای پشتیبانی‌شده

| اندیکاتور | تنظیمات |
|---|---|
| RSI | دوره ۱۴ (روش Wilder) |
| باندهای بولینگر | دوره ۲۰، انحراف معیار ۲ |
| MACD | ۱۲، ۲۶، ۹ (شامل خط سیگنال و هیستوگرام) |
| ایچیموکو | تنکان‌سن (۹) و کیجون‌سن (۲۶) |
| حجم معاملات | مقایسه با میانگین ۲۰ کندل (کم، عادی، بالا، بسیار بالا) |

### صرافی‌ها و تایم‌فریم‌ها

- **صرافی‌ها:** BingX، LBank، CoinEx، MEXC، Bitget
- **تایم‌فریم‌ها:** ۱ دقیقه، ۵ دقیقه، ۱۵ دقیقه، ۳۰ دقیقه، ۱ ساعت، ۴ ساعت، روزانه، هفتگی
- **تعداد کندل:** بین ۱۰ تا ۵۰۰

اگر صرافی‌ای تایم‌فریم انتخابی را پشتیبانی نکند، برنامه پیام خطا همراه با تایم‌فریم‌های مجاز را نشان می‌دهد.

## پیش‌نیازها

- پایتون نسخه ۳.۹ یا بالاتر


## نصب

۱. فایل‌های پروژه را در یک پوشه قرار دهید (حداقل `main_app.py` و `requirements.txt`).

۲. (پیشنهادی) یک محیط مجازی بسازید و فعال کنید:

```bash
python -m venv venv

# ویندوز
venv\Scripts\activate

# لینوکس و مک
source venv/bin/activate
```

۳. وابستگی‌ها را نصب کنید:

```bash
pip install -r requirements.txt
```

یا به صورت دستی:

```bash
pip install pywebview ccxt pandas openpyxl
```

## اجرا

```bash
python main_app.py
```

پنجره برنامه باز می‌شود.

## راهنمای استفاده

1. **صرافی** را از لیست انتخاب کنید.
2. **نماد** را بنویسید. اگر فقط `BTC` بنویسید، به صورت خودکار `BTC/USDT` در نظر گرفته می‌شود.
3. **تایم‌فریم** و **تعداد کندل** را مشخص کنید.
4. روی **دریافت داده** بزنید (یا در فیلد نماد Enter بزنید).
5. نتیجه را ببینید:
   - بالای صفحه: قیمت آخر، درصد تغییر نسبت به کندل قبل و دامنه کندل آخر
   - کارت‌ها: RSI، بولینگر، MACD، ایچیموکو و حجم
   - پایین صفحه: جدول کندل‌ها
6. برای دیدن مقدار همه اندیکاتورها در جدول، گزینه **نمایش همه اندیکاتورها** را فعال کنید.
7. **ذخیره در اکسل** فایل `.xlsx` را در پوشه‌ای که برنامه از آن اجرا شده می‌سازد. نام فایل شامل نماد، تایم‌فریم و زمان ذخیره است. این دکمه بعد از اولین دریافت موفق فعال می‌شود.
8. **کپی جدول** ستون‌های قابل‌مشاهده را برای چسباندن در اکسل یا هر برنامه دیگر کپی می‌کند.

## ساختار پروژه

```
main_app.py        
requirements.txt   
README.md          
```

داخل `main_app.py` سه بخش وجود دارد:

1. دریافت داده با ccxt و محاسبه اندیکاتورها
2. رابط کاربری (HTML، CSS و JavaScript)
3. کلاس `MarketDataAPI` که رابط کاربری را به پایتون وصل می‌کند

### افزودن صرافی جدید

صرافی را هم در `SUPPORTED_EXCHANGES` و هم در گزینه‌های لیست کشویی HTML (`<select id="exchange">`) اضافه کنید. شناسه صرافی باید همان شناسه‌ای باشد که ccxt استفاده می‌کند.
