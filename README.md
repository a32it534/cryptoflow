# CryptoFlow 📈

CryptoFlow یک داشبورد دسکتاپ مدرن و سبک برای تحلیل داده‌های بازار ارز دیجیتال است. این ابزار به معامله‌گران کمک می‌کند تا به راحتی داده‌های لحظه‌ای (Candles) را از صرافی‌های معتبر دریافت کرده، شاخص‌های تکنیکال را مشاهده کنند و گزارش‌های تحلیل خود را برای بررسی‌های بیشتر در قالب فایل اکسل خروجی بگیرند.

## 🚀 ویژگی‌های کلیدی
- **اتصال به صرافی‌های جهانی:** استفاده از کتابخانه قدرتمند CCXT برای دریافت داده از صرافی‌هایی مانند KuCoin، BingX و LBank.
- **رابط کاربری تعاملی:** طراحی مدرن دسکتاپ بر پایه تکنولوژی وب (PyWebView) برای تجربه کاربری روان.
- **خروجی اکسل:** امکان ذخیره آسان دیتای دریافتی در قالب فایل `.xlsx` جهت تحلیل‌های آفلاین.
- **پردازش سریع:** استفاده از Pandas برای مدیریت و پردازش دیتای بازار.

## 🛠 تکنولوژی‌های استفاده شده
- **Python 3.x**
- **PyWebView:** برای ساخت محیط دسکتاپ با تکنولوژی وب.
- **CCXT:** برای تعامل استاندارد با API صرافی‌های کریپتو.
- **Pandas & Openpyxl:** برای پردازش داده‌ها و ایجاد فایل‌های اکسل.
